# 대사 출력기 (템플릿)

두 캐릭터의 대사 · 표정 · 세계관을 모아 두고, 캐릭터를 누르면 대사를 말하게 하는 웹 앱입니다.
이 코드를 내 GitHub에 올리고, 내 Supabase DB에 연결해서 내 캐릭터로 씁니다.

## 시작하기

1. **내 GitHub로 가져오기**
   이 저장소에서 **Fork**(또는 **Use this template**)를 누릅니다.
   zip으로 받았다면 새 저장소를 만들고 압축을 푼 파일을 전부 올립니다.

2. **Supabase 프로젝트 만들기**
   [supabase.com](https://supabase.com)에서 무료 프로젝트를 하나 만든 뒤,
   왼쪽 메뉴 **SQL Editor**에 [`supabase/schema.sql`](supabase/schema.sql) 내용을 전부 붙여넣고 **Run**을 누릅니다.

3. **GitHub Pages 켜기**
   내 저장소의 **Settings → Pages**에서 Branch를 `main` / `(root)`로 두고 **Save**.
   1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생깁니다.

4. **DB 연결**
   사이트를 처음 열면 연결 입력창이 뜹니다.
   Supabase의 **Project Settings**에서 **Project URL**과 **Publishable key**(예전 이름: anon key)를 복사해 넣습니다.
   한 번 연결하면 그 브라우저에서는 다시 묻지 않습니다.

5. **캐릭터 · 아이템 채우기**
   - 빈 캐릭터 칸을 누르면 기본 이미지 · 이름 · 컬러를 넣는 창이 열립니다.
   - 빈 아이템 칸을 누르면 아이템 이미지 · 이름 · 설명을 넣습니다.
   - 이미지는 파일로 올려도 되고, 이미지 주소를 붙여넣어도 됩니다.

## 화면에서 바꾸는 것

| 무엇 | 어디서 |
| --- | --- |
| 캐릭터 기본 이미지 · 이름 · 컬러 | 위의 **설정** → A / B 탭 (빈 캐릭터 칸을 눌러도 열림) |
| 아이템 4칸 | 빈 칸을 누르거나, 채워진 칸 → **수정** |
| 마우스를 따라다니는 캐릭터 그림 | **설정** → 기타 (넣지 않으면 보이지 않음) |
| 배경 음악 | **설정** → 기타 |
| DB 연결 바꾸기 · 지우기 | **설정** → 기타 |
| 세계관 · 표정 · 대사 | 세계관 목록 / 표정 목록 / 캐릭터 아래 ≡ + |

컬러를 고르지 않으면 회색이고, 고른 색은 바꾸지 않고 그대로 씁니다.
말풍선 · ≡ + · 대사 창처럼 캐릭터에 딸린 곳은 그 캐릭터 색이고, 나머지(위의 압정 · 효과음 · AUTO, 음악 재생바, 새 버전 알림, 세계관 바)는 A · B 의 중간색입니다.
설정은 모두 DB에 저장되므로 다른 기기에서도 같은 모습으로 보입니다.

## 코드에서 바꾸는 것

- **앱 이름**: `index.html`의 `<title>`과 `apple-mobile-web-app-title`, `manifest.webmanifest`의 `name` · `short_name`
- **연결창 없이 항상 내 DB로 열기**: `js/config.js`에 주소와 키를 적습니다.
  이 경우 사이트를 여는 모든 사람이 내 DB를 보게 되니, 혼자 쓰는 사이트일 때만 쓰세요.
- **아이콘**: `icons/icon.svg`를 고친 뒤 `node icons/build-icons.mjs` (playwright 필요)
- 코드를 고쳐 올릴 때는 `npm run release`를 한 번 돌려 주세요. 이미 설치된 앱에 "새 버전이 있어요"가 뜹니다.

## 알아 둘 것

- **secret 키나 service_role 키는 절대 넣지 마세요.** 입력창에서도 막습니다.
- 연결 정보는 브라우저에만 저장됩니다. 사이트 주소를 누가 열어도 연결창만 보일 뿐 내 데이터는 보이지 않습니다.
  다만 Publishable key와 주소를 아는 사람은 DB를 읽고 쓸 수 있으니, 키는 남에게 주지 마세요.
- 다른 기기 · 브라우저에서는 연결 정보를 한 번 더 입력해야 합니다.
